# Admin Dashboard

A modern, fully responsive admin dashboard built with React and TypeScript.

## Live Demo
[View Live](https://admin-dashboard-one-beta-27.vercel.app)

## Tech Stack
- **React** + **TypeScript**
- **TanStack Query** — data fetching & cache management
- **MUI DataGrid** — data tables
- **Recharts** — charts & analytics
- **SCSS** — styling
- **React Router DOM** — routing
- **Vite** — build tool

## Features
- **Users** — view, add, delete users with full validation
- **Products** — manage products with stock tracking
- **Orders** — create and manage orders with status badges
- **Inventory** — track stock levels with low stock warnings
- **Analytics** — revenue trends, user acquisition charts, category distribution
- **Settings** — profile management and system preferences
- **Dark Mode UI** throughout
- **Fully Responsive** — mobile, tablet, desktop

## Getting Started
```bash
# Clone Repo
git clone https://github.com/maeez/admin-dashboard.git

# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
```
